Тестовое задние на Britix со стеком Spting(Java) + html + tailwindcss + js
1. Проект запускать с версии JDK 17 и нужен тестовый портал битрикса24, а также git для клонирования репозитория

Для подключения приложения к собственному порталу необходимо:
1.Создать тестовый облачный портал Bitrix24. 

2.Открыть раздел разработчика и создать входящий вебхук.

3.Предоставить вебхуку необходимые права для работы с CRM и каталогом товаров.

4.Скопировать URL созданного вебхука. Он используется серверной частью приложения для обращения к REST API Bitrix24.

5.Добавить в каталог Bitrix24 не менее восьми товаров, указав их названия и цены.

Вебхук использует секретку, поэтому его нельзя публиковать в открытом репозитории. Для локальной разработки можно создать файл application-local.properties, указать в нём URL своего вебхука и исключить этот файл из git с помощью .gitignore.

Поэтому нужно будет в корне проекта создать файл с названием application-local.properties(на одном уровне с application.properties) и туда прописать реальный вебхук
bitrix24.webhook.url=https:// ... /

При повторном отправлении заказа:

В текущей реализации каждая успешная отправка заказа создаёт новую сделку в битрикс. Если пользователь отправит один и тот же заказ повторно, может быть создана дублирующая сделка.

На время отправки кнопка оформления заказа блокируется, чтобы предотвратить случайные повторные нажатия.

Для полноценной защиты можно добавить механизм идемпотентности: присваивать каждому заказу уникальный идентификатор и проверять, обрабатывался ли он ранее. Тогда повторный запрос не будет создавать новую сделку.
